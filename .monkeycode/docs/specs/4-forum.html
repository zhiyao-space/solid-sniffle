=====================================================

入口：底部导航 → 论坛图标

参考来源：Reddit（子版块+投票+Karma）/ Twitter X（短帖+热搜+转发）/ Instagram（视觉流+私信）/ Discord（频道+角色权限）/ 贴吧（吧主+盖楼）

=====================================================

一、论坛首页布局

-----------------------------------------------------
1. Homepage 信息流

- 顶部：搜索栏 + 刷新按钮
- Tab 切换：关注 / 推荐 / 最新 / 热搜
- 帖子卡片：头像 + 用户名 + 内容 + 图片预览 + 互动数据
- 互动数据：点赞数 / 评论数 / 收藏数 / 转发数
- 底部导航：首页 / 圈子 / 私信 / 我的

-----------------------------------------------------
1.2 热搜页

- 模拟 Reddit Hot / Twitter Trending
- 热搜关键词列表（1-10 排名）
- 每条带热度值（浏览数 / 讨论数）
- 点击热搜关键词 → 跳转到包含该话题的帖子列表
- 热搜由系统定时刷新（来源：角色发帖 + NPC 发帖 + 用户发帖的聚合）

-----------------------------------------------------
1.3 圈子页

参考 Reddit 的 subreddit / 贴吧的"吧"

- 展示已加入的圈子列表
- 每个圈子：封面图 + 名字 + 简介 + 成员数 + 今日活跃度
- 发现新圈子：系统推荐 + 用户自建

=====================================================

二、发帖系统

-----------------------------------------------------
2.1 发帖按钮

- 右下角 FAB 悬浮按钮
- 点击弹出选择面板：文字帖 / 图片帖 / 投票帖 / 接力帖 / 匿名帖

-----------------------------------------------------
2.2 文字帖

- 输入框（限制 500 字，仿 Twitter 的简洁感）
- 可选：添加 tag / 定位 / 配图
- 实名 / 匿名切换开关
- 选择发布到哪个圈子

-----------------------------------------------------
2.3 图片帖

- 支持从相册导入图片
- 或输入文字描述 → 由 AI 生成图片描述（帖子中显示为"点击查看图片描述"）
- 多图显示：首图大图 + 其余缩略图折叠

-----------------------------------------------------
2.4 投票帖（参考 Reddit Poll）

- 设置问题 + 多个选项（2-6 个）
- 单选 / 多选切换
- 设截止时间（可选）
- 发帖后其他用户可以投票，实时显示票数分布

-----------------------------------------------------
2.5 接力帖（玩法卡）

- 发帖人设定初始内容和规则
- 后续每个回复者接力往下写
- 适合写故事、续片段、造梗
- 帖子详情中显示接力进度条

=====================================================

三、圈子 / 子版块系统

-----------------------------------------------------
3.1 创建圈子

- 输入：圈子名 + 简介 + 封面图
- 选择：公开 / 私密
- 设置圈规（可 AI 辅助生成）
- 绑定世界书（让帖子和角色遵守该世界观）

-----------------------------------------------------
3.2 进入圈子

- 顶部展示：圈子名 + 头像 + 简介 + 已加入状态
- 圈内 Tab：全部 / 热门 / 最新 / 精华
- 侧边栏：圈子成员列表

-----------------------------------------------------
3.3 圈内匿名模式

- 参考 Reddit 的匿名发帖 + 贴吧的"吧"匿名
- 每局匿名有独立马甲池（3-5 个马甲名）
- 角色/NPC 用马甲发帖时不会暴露真实身份

=====================================================

四、帖子详情与盖楼

-----------------------------------------------------
4.1 帖子详情页

- 顶部：帖子内容 + 发帖人信息
- 评论区：嵌套式评论（最多 3 层，参考 Reddit）
- 右侧：点赞 / 点踩 / 收藏 / 转发按钮
- 底部：输入框"写下回复…"

-----------------------------------------------------
4.2 评论机制

- 用户评论后，角色/NPC 有概率自动回复
- 回复按时间线顺序展示
- 长帖支持"展开更多回复"
- 支持回复他人评论（@对方）
- 支持举报 / 拉黑

-----------------------------------------------------
4.3 刷新盖楼

- 帖子详情页点击"刷新"
- 系统生成 2-5 条新回复，来自角色/NPC
- 不会编造不存在的事实，回复带上下文

=====================================================

五、投票系统

-----------------------------------------------------
5.1 Upvote / Downvote（参考 Reddit）

- 每个帖子 / 评论都有 ↑ ↓ 按钮
- 点上下影响排序权重

-----------------------------------------------------
5.2 Karma 积分

- 用户获得 Karma = 发帖点赞 + 评论点赞 - 点踩
- 发帖 Karma 和评论 Karma 分开统计
- 显示在"我的"页面
- 部分圈子解锁需要最低 Karma（可设）

=====================================================

六、私信系统

-----------------------------------------------------
6.1 私信列表

- 两个 Tab：好友 / 陌生人
- 每条显示：头像 + 名字 + 最后一条消息 + 时间

-----------------------------------------------------
6.2 私信对话

- UI 仿 Instagram 私信
- 支持文字 / 图片 / 表情包
- 发帖后对方有概率主动私信你
- 陌生人私信显示在"陌生人"Tab，不直接混入好友

-----------------------------------------------------
6.3 转发帖子到私信

- 帖子详情页 → 分享按钮 → 选择私信对象
- 转发后生成一张帖子卡片
- 对方点击卡片可以直接跳转原帖
- 角色会对转发的内容做出真实回复

=====================================================

七、个人主页

-----------------------------------------------------
7.1 用户主页

参考 Twitter 个人主页

- 顶部横幅图 + 圆形头像
- 昵称 + @用户名 + 签名
- 数据：关注数 / 粉丝数 / 获赞数
- Tab：帖子 / 回复 / 收藏

-----------------------------------------------------
7.2 关注 / 粉丝

- 关注角色：角色发的帖子会出现在你首页
- 角色也会发动态 / 点赞 / 评论你的帖子
- 角色有自己的主页展示帖子

-----------------------------------------------------
7.3 论坛马甲 / 小号

- 用户可以切换不同马甲发帖
- 每个马甲独立身份，角色可能认不出你
- 但角色知道真实身份后，所有马甲记忆会连接

=====================================================

八、NPC 生态

-----------------------------------------------------
8.1 路人发帖

- 角色/NPC 会按人设随机发帖
- 帖子内容遵守人设和世界观
- 你不会一开始就认出是谁

-----------------------------------------------------
8.2 路人互动

- 你发帖后，角色/NPC 有概率来评论
- 同一 NPC 碰多了会记住你
- 合不来的会继续吵

-----------------------------------------------------
8.3 圈主 / 版主

- 每个圈子有圈主
- 圈主可以：置顶 / 加精 / 封帖 / 踢人 / 修改圈规
- 随机触发封帖事件（增加真实感）

=====================================================

九、特色玩法卡片

-----------------------------------------------------
9.1 Twitter 体短帖

- 每条帖限 280 字
- 支持 Thread（连发多条组成一条长帖）
- 支持引用转发（转发 + 加自己的评论）

-----------------------------------------------------
9.2 Instagram 体视觉帖

- 以图片为主导
- 配文简短
- 评论区分层（粉丝 / 路人 / NPC 的回复风格不同）

-----------------------------------------------------
9.3 同人文追更

- 同人圈专属玩法
- 发帖人写第一章 → 其他人评论催更 / 点菜 / 许愿番外
- 支持定制同人文（设定大纲、CP、字数、文风、结局）

-----------------------------------------------------
9.4 沉浸式推演事件

- 发起一个事件 → 看着它慢慢引爆
- 用户可以选择后续处理方式
- 适合玩娱乐圈抓马、豪门八卦

-----------------------------------------------------
9.5 规则怪谈体

- 发帖人设计规则 → 路人通过提问推理真相
- 发帖人不能直接说谎，但可以误导
- 适合悬疑向玩法

=====================================================

十、记忆互通

-----------------------------------------------------
10.1 论坛 ↔ 聊天 记忆同步

- 你在论坛发的帖 / 评论，角色之后在聊天中会提到
- 角色在论坛发的帖，你也能在聊天中聊到
- 支持设置"遗忘轮数"，模拟几天不看就忘记

-----------------------------------------------------
10.2 跨帖子记忆

- NPC 能记住你最近发过的帖子
- 在不同帖子下碰到你，可能认出你

=====================================================

十一、通知系统

-----------------------------------------------------
11.1 通知类型

- 有人评论了你的帖子
- 有人私信了你
- 你的帖子被赞 / 收藏 / 转发
- 你关注的角色发了新帖
- 圈主置顶 / 加精通知

-----------------------------------------------------
11.2 通知队列

- 模拟真实时间线，不是即时全部显示
- 每隔一段时间推送一条新通知
- 点击通知直达对应页面

=====================================================

数据模型：
{
  forums: [
    {
      id: string,
      name: string,
      description: string,
      coverImage: string,
      isPrivate: boolean,
      rules: string,
      boundWorldBookIds: string[],
      members: string[],
      posts: string[]
    }
  ],
  posts: [
    {
      id: string,
      forumId: string,
      author: string,        // 用户ID 或 角色ID
      authorName: string,    // 显示的昵称（可能是马甲）
      content: string,
      images: string[],
      tags: string[],
      location: string,
      isAnonymous: boolean,
      upvotes: number,
      downvotes: number,
      comments: string[],
      shares: string[],
      createdAt: number,
      type: 'text' | 'image' | 'poll' | 'relay'
    }
  ]
}

=====================================================

防摆件要求：
- 每个帖子卡片点击 → 跳转帖子详情页
- 点赞按钮点击 → 数字 +1，颜色变化，不能重复点
- 评论输入 → 发送后显示在评论区
- 刷新按钮 → 生成 2-5 条新回复
- 私信 → 点击角色头像 → 跳转到对话
- 转发 → 选择对象 → 生成卡片消息
- 收藏 → 收藏图标变化，存入收藏列表
- 关注 → 关注按钮变化，该角色帖子加入信息流

每一步必须能点、有反馈、有数据写入。
