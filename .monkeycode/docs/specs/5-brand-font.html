=====================================================

【一、标识名称显示】

必须实现的显示位置：
1. 顶部导航栏中央显示手机名称（如"空蚀纪"）
2. 锁屏界面底部显示手机名称 + 个性化签名
3. 侧边栏/设置页顶部显示头像 + 名称
4. 每个独立功能模块内部也显示当前模块名

显示效果要求：
- 名称用自定义字体渲染，不能是系统默认字体
- 支持中英文混合显示
- 名称旁可带一个小图标/logo
- 点击名称可跳转"关于"页面（显示版本信息/开发者署名）

【二、字体美化方案】

整体风格定位：高级感 + 暗黑系 + 液态玻璃质感

字体层级（必须分层级设置）：

1. 大标题 / 手机名称
   - 推荐风格：书法体 / 瘦金体 / 哥特体
   - CSS font-family: 'Ma Shan Zheng', 'ZCOOL XiaoWei', serif
   - 字重：700（加粗）
   - 字号：24-32px
   - 字间距：2px
   - 建议加载 Google Fonts：Ma Shan Zheng（马善政毛笔字体）

2. 模块标题 / 导航栏
   - 推荐风格：现代细黑体 / 无衬线
   - CSS font-family: 'Noto Sans SC', 'Inter', sans-serif
   - 字重：600（中等偏细）
   - 字号：14-18px
   - 字间距：1.5px

3. 正文 / 聊天消息
   - 推荐风格：圆润清晰 / 小字号但易读
   - CSS font-family: 'PingFang SC', 'Microsoft YaHei', sans-serif
   - 字重：400（常规）
   - 字号：13-15px
   - 行高：1.6

4. 辅助文字 / 时间戳 / 提示
   - 推荐风格：极简细体 / monospace
   - CSS font-family: 'Share Tech Mono', monospace
   - 字重：300（细）
   - 字号：11-12px
   - color：#6b7280（灰调）
   - letter-spacing：0.5px

【三、全局样式要求】

/* font-smoothing 必须加上，否则移动端字体发虚 */
* {
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
  text-rendering: optimizeLegibility;
}

/* 各页面字体继承规则 */
.app-name {
  font-family: 'Ma Shan Zheng', cursive;
  font-weight: 700;
  font-size: 28px;
  letter-spacing: 3px;
  background: linear-gradient(135deg, #ffffff 0%, #a7a7a7 100%);
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
}

.nav-title {
  font-family: 'Noto Sans SC', sans-serif;
  font-weight: 600;
  letter-spacing: 1px;
}

.message-text {
  font-family: 'PingFang SC', sans-serif;
  font-size: 14px;
  line-height: 1.6;
}

.timestamp {
  font-family: 'Share Tech Mono', monospace;
  font-size: 11px;
  letter-spacing: 0.5px;
  color: rgba(255, 255, 255, 0.5);
}

【四、必须加载的外部字体库】

在 index.html 的 head 标签中加入：
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Ma+Shan+Zheng&family=Noto+Sans+SC:wght@300;400;500;600;700&family=Share+Tech+Mono&family=ZCOOL+XiaoWei&display=swap" rel="stylesheet">

【五、字体降级方案】

每个 font-family 必须写 fallback 链，顺序：
自定义字体 → 系统字体 → 通用字体
例如：font-family: 'Ma Shan Zheng', 'Noto Sans SC', sans-serif;
这样网络加载失败时不会变成默认 Times New Roman。

【六、标识名称交互要求】

- 名称点击后有微动画反馈（scale(0.97) + glow 效果）
- 名称区域有自定义光标样式
- 长按名称弹出"修改名称"弹窗（输入框 + 确认按钮）
- 修改后实时生效 + 保存到 localStorage
