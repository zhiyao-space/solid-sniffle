=====================================================

一、设计语言定位

风格关键词：高级黑灰白 / 液态透明玻璃 / 瘦金体 / 英文字符
整体方向：暗调高级感 + 液态玻璃质感的拟态设计

-----------------------------------------------------

二、配色系统（Design Tokens）

1. 核心色板

深色背景层级：
- #000000 纯黑（页面底色）
- #050505 极深灰（卡片底层）
- #0C0C0C 深灰（组件容器）
- #1A1A1A 中深灰（次级面板）
- #242424 中灰（按钮/分割线）

浅色文字层级：
- #FFFFFF 纯白（主标题/重点文字）
- #E5E5E5 米白（正文）
- #A8A8A8 浅灰（副标题/说明）
- #737373 中灰（辅助文字）
- #525252 暗灰（禁用态）

特殊色：
- #111827 深蓝灰（玻璃叠加色）
- rgba(255,255,255,0.08) 玻璃面板底色
- rgba(255,255,255,0.15) 玻璃边框色
- rgba(255,255,255,0.12) 液态高光色

2. 渐变定义

glass-gradient：linear-gradient(145deg, rgba(255,255,255,0.12), rgba(255,255,255,0.04))
liquid-gradient：radial-gradient(circle at 30% 20%, rgba(255,255,255,0.2), transparent 60%)
blur-mask：linear-gradient(to bottom, rgba(0,0,0,0.3), transparent)

-----------------------------------------------------

三、字体系统

1. 中文字体

- 主字体：LXGW WenKai / 阿里巴巴普惠体 3.0（开源免费）
- 替代：系统默认 sans-serif

2. 英文字体

- 主字体：Inter / JetBrains Mono（等宽数字感）
- 装饰字体：Dela Gothic One（大写标题）

3. 字号层级

- 巨标题：32px / 700（锁屏时间）
- 大标题：24px / 600（页面标题）
- 标题：18px / 600（组件标题）
- 正文：14px / 400（常规文字）
- 辅助：12px / 400（说明文字）
- 微型：10px / 300（状态栏/角标）

4. 字间距

- 英文大写：letter-spacing: 0.08em
- 英文小写：letter-spacing: 0.02em
- 中文数字：letter-spacing: 0.04em

-----------------------------------------------------

四、玻璃拟态系统（核心）

1. 玻璃面板基础样式

.class {
  background: rgba(255,255,255,0.06);
  backdrop-filter: blur(24px) saturate(120%);
  -webkit-backdrop-filter: blur(24px) saturate(120%);
  border: 1px solid rgba(255,255,255,0.12);
  box-shadow:
    0 4px 30px rgba(0,0,0,0.3),
    inset 0 1px 0 rgba(255,255,255,0.1);
}

2. 液态高光效果

伪元素 ::before 实现流动光感：
- 背景：radial-gradient(circle at var(--x) var(--y), rgba(255,255,255,0.25), transparent 40%)
- 鼠标移动时通过 JS 更新 --x, --y 变量
- 实现"液态"跟随效果

3. 透明度层级

- 一级（12%）：卡片/容器
- 二级（8%）：面板叠加层
- 三级（5%）：背景装饰层
- 不透明度：0.88～0.95（确保文字可读）

-----------------------------------------------------

五、组件样式规范

1. 卡片/容器

- 圆角：24px（大卡片）、18px（小组件）
- 内边距：16px
- 阴影：双层阴影（外层扩散 + 内层高光）
- 边框：1px solid rgba(255,255,255,0.1)

2. 按钮

- 高度：44px
- 圆角：999px（胶囊形）
- 背景：rgba(255,255,255,0.08)
- 悬停：背景提升至 rgba(255,255,255,0.14)
- 按下：transform: scale(0.98)

3. 输入框

- 背景：rgba(0,0,0,0.3)
- 边框：1px solid rgba(255,255,255,0.1)
- 聚焦：边框变为 rgba(255,255,255,0.25)
- 圆角：14px

4. 滚动条（隐藏式）

- 宽度：0px / opacity: 0
- hover 时显示细条（4px 宽）

-----------------------------------------------------

六、动画与动效

1. 页面切换

- direction：fade + slide（300ms / ease-out）
- 进入：opacity 0→1, transform translateY(12px)→0

2. 卡片点击

- 按下：scale(0.97)
- 释放：scale(1) 弹性回弹

3. 液态光效

- 鼠标移动时实时更新光点位置
- 离开后光点缓慢消散（transition 500ms）

4. 布局拖拽

- 拖拽中：opacity: 0.7, transform: scale(1.05)
- 放置：弹性过渡（spring-like）

-----------------------------------------------------

七、自定义桌面组件系统

1. 组件类型架构

组件分类：
- 信息组件：时间、天气、电量、日期
- 媒体组件：音乐播放器（播放/暂停、进度条、专辑封面）
- 角色组件：头像栏、背景图、角色文案
- 快捷组件：快捷入口、常用功能按钮
- 自定义组件：用户自建文案卡片

每个组件的基础属性：
{
  id: string,           // 组件唯一 ID
  type: string,         // 组件类型
  x: number, y: number, // 桌面位置坐标
  width: number,         // 组件宽度
  height: number,        // 组件高度
  title: string,         // 标题文字
  content: string,       // 内容文字
  imageUrl: string,      // 自定义背景图 URL
  opacity: number,       // 透明度 0～1
  theme: 'glass' | 'solid' | 'transparent'
}

2. 时间组件

样式方案：
- 方案A：大数字横排（HH:MM，32px 瘦金体）
- 方案B：小数字竖排（日期在上、时间在下）
- 方案C：英文格式（MON 25 / 14:30）
支持自定义：字体大小、格式、颜色、是否显示秒

3. 天气组件

展示：温度（大）+ 天气图标 + 城市名（小）
数据来源：设置页配置的城市 API
样式选项：极简数字版 / 全信息版

4. 音乐组件

展示：专辑封面（正方形缩略图）+ 歌名 + 播放控制
功能：播放/暂停/下一首（调用当前播放状态）
样式：迷你版（只封面+进度条）/ 完整版

5. 角色头像栏组件

展示：头像圆形裁剪 + 角色名 + 自定义文案
支持：头像自定义、背景图自定义、文案编辑
位置：桌面任意位置 + 聊天页顶部固定

6. 自定义文字组件

功能：用户自由输入文案
样式选项：
- 纯文字（无背景）
- 玻璃底（半透明面板）
- 图片底（自定义背景图 + 文字叠加）
字体、字号、颜色、对齐方式均可调

-----------------------------------------------------

八、壁纸与背景系统

1. 壁纸类型

- 锁屏壁纸
- 桌面壁纸
- 组件背景图
- 聊天页背景图

2. 图片导入流程

用户相册选择 → 压缩优化（最大 1920px 宽）→ 生成 blob URL → 存入 IndexedDB → 应用

3. 图片编辑功能

- 裁剪（1:1 / 16:9 / 自由裁剪）
- 缩放与移动
- 暗色滤镜叠加（确保文字可读）
- 模糊背景（用于锁屏匹配）

4. 壁纸效果

- 暗色遮罩：rgba(0,0,0,0.35) 固定在图片上方
- 视差滚动：桌面滑动时壁纸轻微移动

-----------------------------------------------------

九、图标系统

1. 图标风格

- 线性图标（2px stroke）
- 无填充 / 细线条
- 收口端点（stroke-linecap: round）
- 尺寸：24×24px（标准）、32×32px（桌面大图标）

2. 图标颜色方案

- 默认：#FFFFFF @ 0.85 透明度
- 选中态：#FFFFFF（不透明）
- 禁用态：#737373

3. 图标来源

- 使用 lucide-react / feather-icons（开源图标库）
- 所有图标统一风格，禁用 emoji

4. 图标自定义

- 支持从相册导入图片作为自定义图标
- 导入后自动裁剪为圆角正方形
- 长按图标进入编辑模式（替换/删除/重命名）

-----------------------------------------------------

十、布局自定义系统

1. 桌面布局模式

- 锁定模式（默认）：正常使用，不可拖拽
- 编辑模式（长按桌面进入）：组件可拖拽移动、缩放、删除

2. 布局引擎

- 采用 CSS Grid 或绝对定位（absolute + transform）
- 组件位置用 (x, y) 坐标存储
- 支持横向滚动多页桌面

3. 编辑功能

- 拖拽移动组件
- 双指缩放调整组件大小
- 长按删除
- 复制组件
- 锁定单个组件
- 一键重置布局

4. 布局数据存储

{
  desktop: {
    pages: [
      {
        id: 'page1',
        components: [组件对象数组],
        wallpaper: '...'
      }
    ],
    currentPage: 0
  },
  lockscreen: {
    wallpaper: '...',
    components: [组件对象数组]
  }
}

-----------------------------------------------------

十一、主题配置面板（设置页）

配置入口路径：设置 → 美化主题

配置项清单：
1. 壁纸设置：更换桌面壁纸 / 更换锁屏壁纸
2. 字体设置：选择中文字体 / 选择英文字体 / 字号调整
3. 配色微调：主色调、强调色、玻璃透明度
4. 组件管理：添加组件 / 删除组件 / 编辑组件样式
5. 布局编辑：进入桌面编辑模式 / 重置布局
6. 图标自定义：更换系统图标 / 导入自定义图标
7. 暗色遮罩强度：壁纸上方的遮罩透明度

十二、关键 CSS 变量（theme.css）

:root {
  /* 颜色 */
  --bg-primary: #000000;
  --bg-secondary: #050505;
  --card-bg: rgba(255,255,255,0.06);
  --card-border: rgba(255,255,255,0.12);
  --text-primary: #FFFFFF;
  --text-secondary: #A8A8A8;
  --glass-blur: 24px;

  /* 尺寸 */
  --radius-lg: 24px;
  --radius-md: 18px;
  --radius-sm: 12px;
  --nav-height: 60px;
  --card-radius: 16px;

  /* 阴影 */
  --shadow-soft: 0 4px 30px rgba(0,0,0,0.3);
  --shadow-inner: inset 0 1px 0 rgba(255,255,255,0.1);

  /* 动效 */
  --transition-fast: 150ms ease;
  --transition-normal: 300ms ease-out;
}
