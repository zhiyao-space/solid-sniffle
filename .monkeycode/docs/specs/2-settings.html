一、API 配置

入口：设置 → API 配置

设计理念：支持多组 API 预设并存，不同功能可独立绑定不同 API，
不同角色也可以单独绑定不同预设。

1. 聊天 API

- 预设名称（如：主聊天 / 线上 / 线下 / 角色专属）
- Base URL（接口地址，末尾需带 /v1）
- API Key（密码框隐藏显示）
- 模型选择（拉取模型列表，支持选择）
- 上下文条数（控制读取多少轮历史）
- 温度参数（0～2 滑动条）
- 系统提示词注入模式：
  - system 模式（标准）
  - 合并到 user（解决部分 API 不吃 system 的问题）
- 连通性测试按钮（发送测试消息验证）
- 一键保存 / 删除 / 设为默认

2. 生图 API

- 预设名称
- Base URL
- API Key
- 模型选择
- 默认尺寸（512×512 / 768×768 / 1024×1024）
- 风格预设（写实 / 二次元 / 写实插画）

3. 语音 API

- 预设名称
- Base URL
- API Key
- 服务类型选择（TTS 文本转语音 / STT 语音转文本）
- 音色选择 / 自定义音色上传

4. 识图 API（可选）

- 预设名称
- Base URL
- API Key

5. API 预设管理

- 复制一组预设到新名称
- 导入 / 导出预设（JSON 格式）
- 按功能分类查看："聊天用"/"生图用"/"语音用"

入口：设置 → 美化与字体

设计理念：支持多层次的自定义——从"一键套用"到"代码级修改"，
自由度高，从新手到进阶都能用。

-----------------------------------------------------

一、主题管理

1. 官方主题卡列表

- 卡片式展示（封面预览 + 主题名）
- 一键应用主题
- 支持主题评分 / 收藏

2. 自定义配色微调

- 主色调选择器（色盘 + HEX 输入）
- 强调色选择器
- 玻璃透明度滑动条（0%～50%）
- 背景暗度滑动条（0%～80%）
- 实时预览面板（看到当前效果）

3. 主题导入 / 导出

- 导入 .json 主题文件
- 导入 .css 主题文件
- 导出当前主题配置

-----------------------------------------------------

二、CSS 代码导入（高阶自由）

1. 全局 CSS 输入框

- 大号文本域，支持语法高亮
- 粘贴完整 CSS 代码

2. 小组件 CSS 输入框

- 独立样式代码，不影响全局
- 按组件类型分 tab（卡片 / 按钮 / 输入框 / 导航栏）

3. 文件夹批量导入

- 选择本地文件夹
- 自动识别 .css 文件
- 导入后列出文件清单供确认

4. 执行控制

- 导入后自动执行 / 手动执行开关
- 一键撤销上一次修改
- 清除所有美化 / 恢复默认主题

5. 实时预览面板

- 右侧半屏预览当前 CSS 效果
- 切换明暗模式预览

6. 冲突检测

- 提示与现有样式规则的冲突
- 建议优先级调整

-----------------------------------------------------

三、字体设置

1. 中文字体选择

- 系统默认
- 文泉驿
- 阿里巴巴普惠体
- 自定义字体文件导入（.ttf / .otf）
- 字体预览（输入测试文本查看效果）

2. 英文字体选择

- Inter
- JetBrains Mono
- Dela Gothic One（大写标题用）
- 自定义导入

3. 字号全局缩放

- 滑动条（0.8×～1.2×）
- 按页面类型单独设置（桌面 / 聊天 / 设置）

4. 字间距调整

- 英文间距滑动条（-0.02em～0.12em）
- 中文字间距滑动条（0～0.08em）

5. 字体粗细微调

- 标题字重选择（400 / 500 / 600 / 700）
- 正文字重选择

-----------------------------------------------------

四、桌面组件管理

1. 组件列表

- 时间 / 天气 / 音乐 / 快捷入口 / 自定义文案 / 角色头像栏 / 系统信息

2. 添加新组件流程

选择类型 → 自定义内容 → 选择样式 → 拖拽到桌面定位

3. 组件编辑

- 删除 / 复制 / 锁定
- 宽度 / 高度调整
- 透明度滑动条
- 圆角调整（0px～24px）

4. 组件样式预设

- 纯文字版（无背景）
- 玻璃底（半透明面板）
- 图片底（自定义背景图 + 文字叠加）
- 边框版（仅边框，透明底）

3. 裁剪工具

4. 滤镜叠加

- 模糊背景强度滑动条（0px～20px）

5. 壁纸效果

- 一键清空恢复默认
- 视差滚动开关（桌面滑动时壁纸轻微移动）

六、图标设置

1. 图标包选择

- 简约线条（Lucide 默认）
- 填充风格

2. 单图标替换

七、配色预设（快捷方案）

为方便不想手动调色的用户，提供几套预设：

- 纯黑极简：#000000 / #FFFFFF
- 深灰玻璃：#0C0C0C / rgba(255,255,255,0.08)
- 黑白亚系：#000000 / #E5E5E5 / #333333
- 深蓝灰：#0A0F1A / rgba(255,255,255,0.1)

示例数据模型：
{
  theme: {
    name: string,
    colors: {
      bgPrimary: string,
      bgSecondary: string,
      textPrimary: string,
      textSecondary: string,
      accent: string,
      glassOpacity: number
    },
    fonts: {
      cn: string,
      en: string,
      cnSize: number,
      enSize: number,
      letterSpacing: number
    },
    customCss: string
  }
}

三、世界书管理

入口：设置 → 世界书管理

设计理念：全局/局部两态 + 三态挂载 + 注入深度控制，
参考 babo 和叙事诗的世界书设计。

1. 世界书列表

- 书架形式展示所有世界书（封面 + 名称 + 条目数）
- 新建世界书（命名 → 选分类 → 进入编辑）
- 删除 / 复制 / 重命名

2. 世界书编辑

- 条目管理（新增 / 编辑 / 删除 / 复制）
- 条目字段：
  - 名称
  - 内容（支持 Markdown 富文本编辑）
  - 关键词触发（命中关键词自动注入）
  - 注入深度（system / user / 附加上下文）
  - 优先级（1～10，越高越先注入）

3. 注入控制

- 全局世界书开关（影响所有对话）
- 局部世界书（仅绑定特定角色 / 特定对话）
- 三态挂载：始终 / 关键词触发 / 禁用
- 整组世界书一键开关

4. 文件夹导入

- 支持从文件夹批量导入世界书（.txt / .json / .docx 格式）
- 自动识别文件结构 → 建议分类
- 导入后自动建立分组

5. 高级设置

- Token 预算控制（世界书最多占多少 token）
- 世界书命中日志（查看每轮实际注入了哪些条目）

四、角色运行规则

入口：设置 → 角色运行规则

设计理念：参考强制自检思维链 + babo 高级设置，
控制角色回复的底层行为模式。

1. 思维链设置

- 开启 / 关闭思维链
- 思维链模板编辑（文本域，支持导入）
- 预设模板：
  - 强制自检世界书
  - 格式自检
  - 人设一致性检查
  - BEFORE-REPLY 行为准则
- 思维链注入位置（system / 预设 / 每轮拼接）

2. 输出规则

- 每轮输出结构定义（可配置顺序）：
  时间地点天气栏 → 剧情正文 → 状态栏 → 记忆区 → 分割线
- 每部分开关（可单独关闭某栏）
- 输出格式模板（自定义格式）
- 完毕自查标记（自定义结尾符号）

3. 自检机制

- 世界书自检开关（每轮检查是否读取相关世界书）
- 人设自检开关（每轮检查是否与角色设定一致）
- 格式自检开关（检查输出是否符合预设结构）
- 自检报告查看（每轮自检日志）

4. 行为准则

- 四大逻辑防火墙：
  - NO-REPEAT（拒绝车轱辘话）
  - NO-RE-ASK（已答不复问）
  - NO-CONTRADICT（拒绝吃书反转）
  - ANSWER-PENDING（用户提问必有回音）
- 自定义行为准则（用户添加自己的规则）
- 防幻觉机制强度（低 / 中 / 高）

5. 时间感知

- 开启 / 关闭时间感知
- 与系统时间同步
- 自定义时间模式（手动设置当前时间）

6. 记忆同步

- 小总结范围设置（多少轮做一次小结）
- 大总结触发条件（手动 / 达到 N 轮自动）
- 总结内容可编辑后写入世界书

7. 回复参数

- 最大回复长度
- 输出温度（0～2 滑动条）
- 上下文读取条数
- 消息分句（长回复自动分条发送）
