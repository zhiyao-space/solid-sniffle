=====================================================

所有功能必须满足以下要求，否则视为未完成：
1. 每个按钮/图标必须有 onClick 事件
2. 每个弹窗必须有 open/close 状态控制
3. 每个数据操作必须写入 localStorage / IndexedDB
4. 每个页面切换必须有路由或状态管理
5. 禁止只写 CSS 样式描述 → 必须写实际交互逻辑

交互反馈要求：
- 点击按钮必须有视觉反馈（颜色变化 / 缩放 / 震动）
- 加载状态必须有 loading 动画
- 空状态必须有占位提示
- 错误状态必须有错误提示

5.1 角色报备 / 查岗

【查岗按钮】
- 触发：点击聊天页顶部角色状态栏
- 行为：弹出 modal，显示"角色正在做什么"的弹窗
- 弹窗内容：角色当前活动 + 进度条（如"正在工作 65%"）
- 角色回复：根据人设生成一条报备消息，自动发到聊天室
- 数据变更：本次报备内容写入日程记录

【反向报备】
- 触发：点击聊天底栏 + 功能栏 → 选择"报备"
- 行为：弹出选择面板（拍照 / 文字描述 / 语音）
- 用户上传图片后：显示图片预览 + 输入框填写留言
- 点击"提交报备"后：关闭 modal，角色根据图片内容生成回复

5.2 日程功能

【查看日程】
- 触发：点击聊天页顶部 → 点击"日程"标签
- 行为：打开日历视图页面（月视图 / 日视图 toggle）
- 日程列表按时间排序显示
- 点击某条日程 → 弹出该日程的详细信息 + 对话中可删除

【设置固定作息】
- 触发：设置页 → 日程设置 → 添加作息
- 行为：打开时间选择器（开始时间 + 结束时间 + 标签）
- 保存后：该作息加入日程数据，角色到睡觉时间自动切换"昏睡模式"
- 昏睡模式：角色消息延迟回复，弹窗可"叫醒"（唤起对话输入框）

5.3 钱包系统

【转账】
- 触发：聊天底栏 + 功能栏 → 选择"转账"
- 行为：打开转账面板（输入金额 + 备注）
- 输入完成后点"确认转账"：
  - 前端：弹出转账卡片样式消息（仿微信红色卡片）
  - 后端：从用户钱包扣除 → 角色钱包增加 → 写入交易日志
  - UI：显示"转账成功"toast

【发红包】
- 触发：聊天底栏 + 功能栏 → 选择"红包"
- 行为：打开红包面板（金额 + 封面选择 + 祝福语）
- 确认后：显示红包卡片消息（角色头像 + "领取红包"按钮）
- 角色点击领取：红包卡片变成"已领取"状态 + 金额动画

5.4 心声功能

【查看心声】
- 触发：点击消息气泡旁的爱心图标 / 或长按角色头像
- 行为：弹出侧滑面板
- 面板内容结构：
  1. 当前想法（文字）
  2. 状态数值条（心情/健康/理智/好感度）
  3. 情绪波动曲线（简单折线图）
  4. 所在位置
- 关闭方式：点击蒙层 / 点 X / 滑动关闭

5.5 主动消息

【配置】
- 触发：设置页 → 聊天参数 → 主动消息
- 行为：显示开关 + 频率设置（数字输入框 N 次/日）+ 禁扰时段选择器
- 开关开启后：设置浏览器的定时任务（setInterval）

【触发逻辑】
- 条件：当前时间在允许范围内 + 未达到当日次数上限 + 距离上次主动消息间隔 > 配置值
- 执行：调用 AI 生成一条主动消息 → 显示为系统通知横幅 → 点击通知跳转聊天页

5.6 戳一戳

【触发方式】
- 双击角色头像
- 发送特定表情（👆/戳一戳贴纸）

【行为】
- 用户戳角色：显示系统消息"你戳了戳 角色名"
- 角色自动回复：从人设中提取的"戳一戳回复模板"生成回复
- 角色戳用户：显示系统消息"角色名 戳了你一下" + 自定义后缀（如"的脑袋"）

5.7 朋友圈

【发布动态】
- 触发：底部导航 → 朋友圈 → 点"发布"
- 行为：打开编辑器（文字输入 + 图片上传 + 谁可见）
- 发布后：动态卡片显示在时间线中

【互动】
- 点赞：点击爱心图标 → 图标变红 + 计数 +1
- 评论：点击评论框 → 弹出评论输入 → 角色根据人设自动回复评论

5.8 番茄钟

【启动】
- 触发：聊天底栏 + 功能栏 → 选择"一起专注"
- 行为：弹出番茄钟设置面板（时长选择 + 白噪音开关 + 角色是否陪）
- 点击"开始"：
  1. 关闭面板，显示倒计时组件
  2. 角色发送一条陪伴消息
  3. 倒计时结束 → 播放提示音 + 角色发送鼓励消息

【专注中互动】
- 点击图片中角色的不同位置触发不同反应（点击头像/点击身体/点击手中的物品）
- 点击 → 触发对应动画 + 生成一段台词

5.9 分支系统

【创建分支】
- 触发：长按任意历史消息 → 操作面板 → 选择"从此处分叉"
- 行为：复制该节点之前的所有消息到新分支 → 保存分支元数据（父消息 ID + 创建时间 + 分支名）
- UI：顶部显示"分支模式"标识条

【切换分支】
- 触发：设置页 → 分支管理
- 行为：显示分支列表 → 点击切换 → 重新加载该分支的对话历史

【切回主线】
- 触发：顶部标识条点击 → 选择"回到主线"
- 行为：切换 activeChatId 到主线 ID，保留分支数据不删除

交互实现技术要求：

1. 所有弹窗必须有遮罩层（mask），点击遮罩关闭
2. 所有列表必须有空状态占位（empty state）
3. 所有异步操作必须有 loading 状态
4. 所有失败操作必须有错误提示（toast.error）
5. 所有成功操作必须有成功反馈（toast.success）
6. 按钮点击必须有 :active 态（transform: scale(0.97)）
7. 长列表必须虚拟滚动（react-window 或虚拟列表方案）
8. 图片必须懒加载（loading="lazy"）
9. 所有表单提交必须有 loading 态防止重复提交
10. 所有模态框必须有键盘 ESC 关闭
